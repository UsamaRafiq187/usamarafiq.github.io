# Usama Rafiq — Portfolio

Single-page iOS developer portfolio (ice-blue gradient).

## Preview locally

Open `index.html` in a browser, or:

```bash
cd ~/Desktop/usama-portfolio
python3 -m http.server 8080
```

Then visit http://localhost:8080

## WhatsApp

Edit `apps.js` and set:

```js
whatsapp: "923XXXXXXXXX", // digits only, country code included
```

## Upload

Upload the whole folder to GitHub Pages (or any static host). Keep this structure:

- `index.html`
- `styles.css`
- `apps.js`
- `main.js`
- `assets/`
